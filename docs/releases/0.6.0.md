# Strategy Core V3 0.6.0

Tag `strategy-core-v3-v0.6.0`. Both crates are 0.6.0. This release lets a host deliver the
forecast runner's per-station nowcast of the scope's index city, the inputs a Strategy needs
to value an hourly index with the runner's model (FLIP2X's nowcast gate), and the two
calibration fields that valuation needs from MinuteTemp.

## Contract change

Decision V6 contexts encoded under 0.5.0 do not decode under 0.6.0. The wire magics and the
result format are unchanged, and results encode byte for byte as under 0.5.0. Hosts and
Strategy children must move together using the new immutable release tag, commit, crate
archive digest and Decision V6 corpus digest. Do not mix pins, move a published tag, or
reinterpret recorded 0.5.0 contexts as 0.6.0.

- `DecisionContextV6.nowcast: Option<NowcastInputV6>` is appended after `book_window_min`. A
  context without it encodes as under 0.5.0 plus one trailing `None` byte (but see the
  calibration below).
- `NowcastInputV6 { supplied: SuppliedNowcastV6, components: NowcastComponentsV6 { feed } }`
  (`strategy_core_v3::nowcast_v6`, supplied types in `strategy_core_kernel::nowcast`): per
  member station its newest three complete issues (19-quantile forecasts at each lead, issue
  time, the runner's `issued_at`, the host's receipt, bundle, degraded flags, `own_age_min`),
  the versioned model artefacts (`kind`, `model_id`, `version`, `valid_from`, canonical
  `body_json` and its `sha256`, which validation checks), member METARs, the last whole issue
  and the runner heartbeat, plus one `ComponentMetaV4` for the feed's authority and
  `unavailable: Option<NowcastUnavailableReasonV6>`. Fail closed: the feed is `Current`
  without a reason or `Unavailable` with one (`no_key`, `auth_failed`, `disconnected`,
  `stale`, `gap`, `no_artifact`, ...); a gated Strategy does not trade on an unavailable one.
- `SuppliedIndexCalibration` gains `city_reference_c: Option<Decimal>` and
  `published_at_unix_ns: Option<i64>` at its end (MinuteTemp's `calibration` event carries
  both); `IndexCalibration` gains `city_reference_c: Option<f64>` and
  `published_at: Option<DateTime<Utc>>`. A context whose hourly index has a calibration grows
  by these two fields.
- Neither is part of the state fence.
- The kernel reads `StrategyKernelState::nowcast(city) -> Option<&NowcastState>` and
  `NowcastState::available()`. It is a
  provided method returning `None`, so existing hosts and test doubles compile unchanged.

The V6 corpus adds three valid vectors (`nowcast`, `nowcast-unavailable-disconnected`,
`nowcast-unavailable-no-snapshot`) and seven invalid ones (a forecast of a station not in `stations`, an artefact whose body does not hash
to its `sha256`, four issues of one station, quantiles not aligned with their levels, an
unavailable feed without a reason, a current feed with one, a calibration published after the
decision time). Every other context vector is its 0.5.0 bytes plus `00`, and those with a calibration
also carry its two new fields. Results are unchanged.

## Use

```toml
strategy-core-kernel = { git = "https://github.com/McFalljb/strategy-core.git", tag = "strategy-core-v3-v0.6.0", version = "=0.6.0" }
strategy-core-v3 = { git = "https://github.com/McFalljb/strategy-core.git", tag = "strategy-core-v3-v0.6.0", version = "=0.6.0", features = ["kernel"] }
```

A Strategy built on 0.5.0 compiles against 0.6.0 unchanged except where it builds a
`DecisionContextV6`, `SuppliedIndexCalibration` or `IndexCalibration` by struct literal (add
`nowcast: None` and the two calibration fields). Follow [the nowcast contract](../decision-v6.md#nowcast).

## Publish after merge

```bash
commit=$(git rev-parse origin/main)
git tag -a strategy-core-v3-v0.6.0 -m "Strategy Core V3 0.6.0" "$commit"
git push origin strategy-core-v3-v0.6.0
scripts/pin-digests.sh strategy-core-v3-v0.6.0 > pin-digests.txt
gh release create strategy-core-v3-v0.6.0 --verify-tag \
  --title "Strategy Core V3 0.6.0" --notes-file docs/releases/0.6.0.md \
  conformance/v6/decision-transactions.json conformance/v3/vectors.json pin-digests.txt
```

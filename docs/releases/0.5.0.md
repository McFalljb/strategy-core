# Strategy Core V3 0.5.0

Tag `strategy-core-v3-v0.5.0`. Both crates are 0.5.0. This release lets a host deliver,
for each scoped Market, the trailing-window minimum of every bid level's others-only
quantity, which a book-anchored Strategy needs: hourly_ladder's wall deep layer.

## Contract change

Decision V6 contexts encoded under 0.4.0 do not decode under 0.5.0. The wire magics and the
result format are unchanged, and results encode byte for byte as under 0.4.0. Hosts and
Strategy children must move together using the new immutable release tag, commit, crate
archive digest and Decision V6 corpus digest. Do not mix pins, move a published tag, or
reinterpret recorded 0.4.0 contexts as 0.5.0.

- `DecisionContextV6.book_window_min: Option<BookWindowMinV6>` is appended after
  `hourly_index`. A context without it encodes as under 0.4.0 plus one trailing `None`
  byte.
- `BookWindowMinV6 { window_ms, markets: Vec<MarketBookWindowMinV6> }` and
  `MarketBookWindowMinV6 { market_id, yes_bids, no_bids }` reuse `BookLevelV4`, unchanged.
  The field has one entry per scoped Market in order, each Market once, its levels are level for level the
  decision book's, and each quantity is at most the book level's. The window is
  `0 < window_ms <= 60 000`.
- It is not part of the state fence.
- The kernel projection fills `strategy_core_kernel::Book::window_min: Option<BookWindowMin>`,
  and it is `None` without the field.

The V6 corpus adds one valid vector (`book-window-min`) and two invalid ones (a quantity
above the displayed level, and an unbounded window). Every other context vector is its
0.4.0 bytes plus `00`. Results are unchanged.

## Use

```toml
strategy-core-kernel = { git = "https://github.com/McFalljb/strategy-core.git", tag = "strategy-core-v3-v0.5.0", version = "=0.5.0" }
strategy-core-v3 = { git = "https://github.com/McFalljb/strategy-core.git", tag = "strategy-core-v3-v0.5.0", version = "=0.5.0", features = ["kernel"] }
```

Follow [the book window minimum contract](../decision-v6.md#book-window-minimum).

## Publish after merge

```bash
commit=$(git rev-parse origin/main)
git tag -a strategy-core-v3-v0.5.0 -m "Strategy Core V3 0.5.0" "$commit"
git push origin strategy-core-v3-v0.5.0
scripts/pin-digests.sh strategy-core-v3-v0.5.0 > pin-digests.txt
gh release create strategy-core-v3-v0.5.0 --verify-tag \
  --title "Strategy Core V3 0.5.0" --notes-file docs/releases/0.5.0.md \
  conformance/v6/decision-transactions.json conformance/v3/vectors.json pin-digests.txt
```

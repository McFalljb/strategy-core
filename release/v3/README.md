# Strategy Core V3 release payload

This directory is generated by `python scripts/build_v3_release.py`. Do not edit generated manifests, digests, corpus copies, consumer locks, or artifacts by hand.

Qualification consumers must resolve the HTTPS release URLs and verify the recorded SHA-256 before use. Rust consumers must copy the released `rust-consumer.Cargo.lock`, fetch its locked registry dependencies into a clean Cargo home, and test with `--locked`; generating a lock from an ambient offline cache is not qualification. Git branches, Git branch archives, sibling paths, editable installs, and `file:` URLs are not qualification inputs.

Publication remains blocked until an administrator externally verifies and attests GitHub immutable releases and a no-bypass tag ruleset that blocks updates and deletion for `strategy-core-v3-v*`. Repository files do not establish those settings.
